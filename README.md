## 🌟 الميزات الرئيسية للمنصة

### 🎓 1. بوابة الطلاب (`/`)
- **شاشة افتتاحية متحركة (Feature 13):** شاشة ترحيبية لمدة 2.4 ثانية تعرض شعار المنصة الذهبي وفريق العمل (مازن شكري، رحمة علاء، وليد محرم) مع زر تخطي فوري ومزامنة للجلسة.
- **شريط الأخبار العاجلة المتحرك (Feature 10):** شريط إخباري متحرك بانسيابية من اليمين لليسار. *يختفي تلقائياً بالكامل في حال عدم وجود أخبار نشطة في قاعدة البيانات (صفر بيانات وهمية).*
- **عداد الامتحانات التنازلي المباشر (Feature 26):** عرض حي للأيام، الساعات، الدقائق، والثواني المتبقية على الامتحانات مع إمكانية التحكم الكامل به من لوحة المشرفين.
- **تصفية ذكية للفرق والمواد (Feature 1):**
  - أزرار الفرق الدراسية الأربعة: `الفرقة الأولى`، `الفرقة الثانية`، `الفرقة الثالثة`، `الفرقة الرابعة`.
  - جلب ديناميكي لحظي للمواد المقررة لكل فرقة من Supabase.
  - تصفية حسب نوع المحتوى: الكل، محاضرات PDF، فيديوهات شرح مباشرة.
- **بحث فوري حي (Feature 2):** تصفية آنية للمحاضرات والملخصات بالاسم، الموضوع، أو الشرح دون الحاجة لإعادة تحميل الصفحة.
- **بطاقات المحاضرات وشارة "جديد" لـ 72 ساعة (Feature 5 & 23):**
  - شارة متوهجة "جديد / NEW" تلقائية لأي ملف أو فيديو تم رفعه خلال آخر 3 أيام (72 ساعة).
  - إظهار ملاحظات وتوجيهات المشرف بوضوح على كل بطاقة.
  - مشغل فيديو HTML5 تفاعلي متجاوب يدعم سرعات تشغيل متعددة (0.75x, 1x, 1.25x, 1.5x, 2x)، ملء الشاشة، وترجيع/تقديم 10 ثوانٍ.
  - إمكانية معاينة وتحميل ملفات PDF مباشرة.
- **زر تفاعل "مفيد 👍" (Feature 11):** عداد تفاعلي يزيد لحظياً في Supabase مع منع التكرار العشوائي لنفس الجلسة.
- **تبديل الوضع الليلي / النهاري (Feature 4):** ثيم داكن ملكي (كحلي وذهبي) وثيم نهاري ناصع.
- **عزل تام للمسارات (Route Isolation):** لا يحتوي مسار الطلاب نهائياً على أي روابط أو أزرار تشير إلى لوحة التحكم الإدارية.

### 🛡️ 2. لوحة تحكم المشرفين (`/admin-dostour-control`)
- **حماية بكلمة مرور:** التحقق التلقائي ضد `NEXT_PUBLIC_ADMIN_PASSWORD` (الافتراضية: `Dostour@2026`).
- **تسجيل خروج تلقائي:** مؤقت ذكي لمراقبة النشاط يسجل الخروج تلقائياً بعد 30 دقيقة من الخمول لحماية النظام.
- **رفع جماعي متعدد للملفات والفيديوهات (Bulk Upload):**
  - سحب وإفلات أو اختيار ملفات متعددة دفعة واحدة (PDFs أو فيديوهات MP4/WebM).
  - شريط تقدم فردي لكل ملف أثناء الرفع إلى Supabase Storage (`lectures-pdfs` أو `lectures-videos`).
  - تحديد الفرقة، المادة، العنوان، والوصف التوجيهي لكل ملف.
- **إدارة كاملة للمحاضرات (Full CRUD):**
  - تصفية وبحث في جميع المحاضرات المرفوعة.
  - تعديل العناوين، الملاحظات، والمواد.
  - حذف المحاضرة نهائياً (يحذف السجل من قاعدة البيانات والملف من التخزين السحابي فوراً).
- **إدارة المواد الدراسية:** إضافة وحذف المواد وتوزيعها على الفرق الأربعة.
- **إدارة شريط الأخبار العاجلة:** إضافة تنبيهات، تفعيلها أو تعطيلها، وحذفها.
- **التحكم بعداد الامتحانات:** تعديل عنوان الامتحان، الموعد والوقت، وتفعيل أو إيقاف العداد.

## 🚀 تعليمات التشغيل السريع

### 1. إعداد المتغيرات البيئية
قم بنسخ ملف `.env.local.example` إلى `.env.local`:
```bash
cp .env.local.example .env.local
```
وقم بملء بيانات Supabase الخاصة بمشروعك:
```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
NEXT_PUBLIC_ADMIN_PASSWORD=Dostour@2026
```

### 2. تهيئة قاعدة البيانات والتخزين السحابي (Supabase SQL)
قم بنسخ محتويات ملف `supabase_schema.sql` وتنفيذه في قسم **SQL Editor** داخل لوحة تحكم Supabase الخاصة بك:
- ينشئ الجداول: `subjects`، `materials`، `lecture_bundles`، `lecture_ratings`، `quizzes`، `quiz_questions`، `quiz_submissions`، `french_terms`، `student_requests`، `urgent_news`، `settings`، `site_settings`.
- ينشئ دوال الزيادة الذرية `increment_likes` و `increment_bundle_downloads`.
- يفعّل سياسات الأمان RLS وصلاحيات القراءة والرفع والحذف العامة.
- ينشئ حاويات التخزين السحابي: `lectures-pdfs`، `lectures-videos`، `thumbnails`، `french-audio`.
- يفعّل اشتراك Realtime اللحظي على كافة الجداول.

### 3. تشغيل خادم التطوير
```bash
npm run dev
```
افتح المتصفح على:
- بوابة الطلاب: [http://localhost:3000](http://localhost:3000)
- لوحة تحكم المشرفين: [http://localhost:3000/admin](http://localhost:3000/admin) أو [http://localhost:3000/admin-dostour-control](http://localhost:3000/admin-dostour-control) (كلمة المرور: `Dostour@2026`)

### 4. بناء نسخة الإنتاج
```bash
npm run build
npm run start
```
